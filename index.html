Pulse core app


Hele din aktivitet samlet et sted


Pulse Core forbindes med dit Pulse Core-sportsur og giver dig et enkelt overblik over din sundhed, træning og daglige aktivitet.


I appen kan du blandt andet følge:

  • Puls og daglige skridt
  • Søvn og restitution
  • Daily Readiness
  • Træningsdata og løberuter
  • Urets batteriniveau

Dine data synkroniseres automatisk, så du nemt kan følge din udvikling og få mere ud af både din træning og restitution.

EASY CONNECT

Pulse Core ur og andre devices

Med Pulse Core uret kan du conecte til både din telefon og dine bluetooth høretelefoner. Du kan fx via din telefon lave en tilpasse rute i Kort-appen og downloade den ned på dit sportsur. Via uret kan du tracke dit løb, cykel, træning og meget - og få data på både ur og telefonen. Da Pulse Core uret har en Bluetooth funktion kan du tilkoble dine høretelefoner, og slipper for ar have telefonen med ud til sport.
